# 国际化自动提取（openI18n）

`openI18n` 用来扫描项目里的国际化 key，并为多语言文件自动补齐内容，适合快速搭建多语言后台。

## 1. 一条命令

```bash
pnpm openI18n
```

## 2. 它会做什么

- 扫描 `src/**/*.vue`
- 识别这些常见写法：
  - `$t('xxx')`
  - `v-t="'xxx'"`
  - `{{ $t('xxx') }}`
  - `t('xxx')`
  - `i18n.global.t('xxx')`
  - `<i18n>` 自定义块
- 按语言生成或补齐 `src/i18n/lang/*.json`

## 3. 语言列表来自哪里

语言配置来自：`src/config/lang.ts`

如果你要新增语言，先改这里，再执行：

```bash
pnpm openI18n
```

## 4. 生成结果放哪里

输出目录：

```text
src/i18n/lang/
```

例如：

- `zh-CN.json`
- `en.json`
- `ja.json`

## 5. 使用时要注意什么

- 该命令会**重新生成语言文件**，所以请把语言包纳入 Git 管理
- 机器翻译只适合做占位，不建议直接拿来做正式线上文案
- 网络不好时，生成结果可能退化成 key 本身

## 6. 推荐工作流

1. 先在页面里正常写 `$t('key')`
2. 执行 `pnpm openI18n`
3. 检查 `src/i18n/lang/*.json`
4. 手工修正文案
5. 提交到仓库

## 7. 适合继续演进的方向

如果项目后期变大，可以把 `openI18n` 升级成：

- 机翻占位
- 人工校对
- 术语表统一维护
- 翻译中台优先覆盖

这样既保留自动化效率，也能保证线上文案质量。
